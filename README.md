# PeersForge

Frontend-only React + React Router student collaboration app.

Features:
- Responsive landing page with images
- Login with no input validation
- Dashboard
- Find Peers with one search bar
- Blank peer and profile photo areas
- Schedule Meetings with name, date, time, type and place
- Meetings saved in localStorage
- Notebook-style My Notes with multiple notebooks
- Notes saved in localStorage
- Simple topic-only Resource Hub
- Editable profile
- Protected routes and 404

Run:
npm install
npm run dev

No backend is required.
